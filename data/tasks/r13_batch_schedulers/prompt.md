Implement the method `_mini_batch_schedulers(self, frac_epoch)` of the class `StepByStep` (write only the class with this method; `__init__` already exists). It is called after every training mini-batch with `frac_epoch`, the fraction of the current epoch already processed (between 0 and 1). The object has the attributes `scheduler` (a learning-rate scheduler or `None`), `is_batch_lr_scheduler` (True when the scheduler must be stepped after every mini-batch), `total_epochs` (epochs started so far, counting the current one) and `learning_rates` (a list). When a mini-batch-level scheduler is configured, the method must advance it and record the learning rate(s) now in effect in `learning_rates`. Epoch-level schedulers must not be touched here.
