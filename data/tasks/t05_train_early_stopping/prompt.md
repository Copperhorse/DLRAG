Implement the method `train(self, n_epochs, seed=42, patience=None)` of the class `StepByStep` (write only the class with this method; `__init__` already exists), like the book's training method but with optional early stopping. The object already has `set_seed(seed)` (makes training reproducible) and `_mini_batch(validation=False)` (runs one pass over the training loader, or over the validation loader when `validation=True`, and returns that pass's loss). The method must train for at most `n_epochs` epochs, keeping track of the training and validation losses and of how many epochs the object has been trained for in total. If `patience` is not `None`, it must stop as soon as the validation loss has failed to improve (become strictly lower than the best one seen so far during this call) for `patience` epochs in a row.
