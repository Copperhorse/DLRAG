Implement the methods `save_checkpoint(self, filename)` and `load_checkpoint(self, filename)` of the class `StepByStep` (write only the class with these two methods; `__init__` already exists and must not be written). The object has the attributes `model`, `optimizer` (a PyTorch optimizer), and the training history. `save_checkpoint` must save everything needed to later resume training to the file `filename`; `load_checkpoint` must restore all of it from that file into the object and leave the model ready for further training.
