Implement the method `_epoch_schedulers(self, val_loss)` of the class `StepByStep` (write only the class with this method; `__init__` already exists). It is called once at the end of every training epoch with that epoch's validation loss. The object has the attributes `scheduler` (a learning-rate scheduler or `None`), `is_batch_lr_scheduler` (True when the scheduler is stepped after every mini-batch instead) and `learning_rates` (a list). When an epoch-level scheduler is configured, the method must advance it, passing the validation loss to schedulers that need a metric to decide, and must then record the learning rate(s) now in effect in `learning_rates`.
