Write a function `make_lr_fn(start_lr, end_lr, num_iter, step_mode='exp')` for a learning-rate range test. It returns a function `lr_fn(iteration)` meant to be given to PyTorch's `LambdaLR` scheduler, which multiplies the optimizer's initial learning rate (`start_lr`) by whatever `lr_fn` returns. Over `num_iter` iterations the learning rate must grow from `start_lr` to `end_lr`: geometrically when `step_mode` is `'exp'` (the default) and linearly when it is `'linear'`.
