Implement the method `loader_apply(loader, func, reduce='sum')` of the class `StepByStep` (write only the class with this method). It is a utility that can be called directly on the class, without an instance, as `StepByStep.loader_apply(loader, func)`. It applies `func(x, y)` to every mini-batch `(x, y)` of the data loader; each call returns a tensor. It must combine the per-batch results into a single result: with `reduce='sum'` add them up over the batches, with `reduce='mean'` average them over the batches; for any other value return the per-batch results stacked into one tensor.
