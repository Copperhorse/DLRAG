Implement the method `correct(self, x, y, threshold=.5)` of the class `StepByStep` (write only the class with this method; `__init__` already exists). The object has `model` and `device`. Given a mini-batch of features `x` and integer labels `y`, it must compute how many samples the model classified correctly, per class, and return a tensor with one row `(number_correct, number_of_samples_in_that_class)` for each class (so a binary problem gives two rows: class 0 then class 1). The model may be a multiclass model (one output per class, the largest wins) or a binary model with a single output, which is either already a probability (when the model is an `nn.Sequential` whose last layer is a `nn.Sigmoid`) or a logit; a binary prediction is class 1 when its probability is greater than `threshold`. Evaluation must not leave the model in a different mode than during training.
