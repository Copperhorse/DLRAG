Write a function `make_accum_train_step_fn(model, loss_fn, optimizer, accum_steps)` that builds and returns a function `perform_train_step_fn(x, y)`, like the training-step builders used in the book, but with gradient accumulation: gradients from `accum_steps` consecutive calls are accumulated and averaged, and the optimizer updates the parameters only once every `accum_steps` calls. The returned function reports the loss of the mini-batch it was called with.
