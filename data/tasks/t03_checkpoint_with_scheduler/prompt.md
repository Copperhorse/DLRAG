Implement the methods `save_checkpoint(self, filename)` and `load_checkpoint(self, filename)` of the class `StepByStep` (write only the class with these two methods; `__init__` already exists), like the book's checkpointing methods but extended to also store and restore the learning-rate scheduler. The object has `model`, `optimizer`, the training history and `scheduler` (a learning-rate scheduler, or `None`). When a scheduler is set, its state must be saved under the additional checkpoint key `'scheduler_state_dict'` and restored on load. Checkpoints saved without a scheduler must still load fine, and loading must never fail only because the scheduler key is missing.
