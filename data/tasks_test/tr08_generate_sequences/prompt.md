Write a function `generate_sequences(n=128, variable_len=False, seed=13)` that creates the toy dataset of the sequence chapters: `n` noisy walks along the corners of a square. The corners are (-1, -1), (-1, 1), (1, 1), (1, -1) in this order. Each sequence starts at a random corner, visits the following corners in this circular order (direction 1, "clockwise") or in the reverse order (direction 0, "counter-clockwise"), and every point gets independent Gaussian noise with standard deviation 0.1. Sequences have 4 points, or, if `variable_len` is True, a random length between 2 and 4. All randomness comes from NumPy's global generator seeded with `seed`, in this order: start corners, lengths (only if `variable_len`), directions, noise. Return `(points, directions)`: a list with one array of shape (length, 2) per sequence and an array with the n directions.
