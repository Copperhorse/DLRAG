Write a function `gradient_history(sbs, layer_name, n_epochs)`. `sbs` is the book's training-helper object with its data loaders already set. Train it for `n_epochs` epochs while recording, with the book's own mechanism for that, the gradients of the parameters of the layer called `layer_name` (as listed by `model.named_modules()`) every time they are computed. Return what was recorded for that layer: a dict from parameter name (`'weight'`, `'bias'`) to the list of recorded gradients, one entry per backward pass. When the function returns, recording must be switched off: training further must not add to the returned lists. Reuse the code of the book's companion repository (its top-level modules are importable) instead of writing the logic yourself.
