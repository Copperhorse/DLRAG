Implement the method `to(self, device)` of the class `StepByStep` (write only the class with this method; `__init__` already exists). The object has a `model` and an attribute `device`. The method must send the model to `device` and remember that device in the attribute. If the device cannot be used (for instance an unknown device name), it must not crash: it falls back to the GPU if one is available and otherwise to the CPU, sends the model there, records that device instead, and prints a short message saying which device it could not use and where it sent the model instead.
