Implement the method `train_with_checkpoints(self, n_epochs, every, template, seed=42)` of the class `StepByStep` (write only the class with this method; `__init__` already exists). The object already has the methods `train(n_epochs, seed=42)`, which trains for that many more epochs and counts them in the attribute `total_epochs`, and `save_checkpoint(filename)`. The new method must train for `n_epochs` epochs in total, in chunks of `every` epochs (the last chunk may be shorter) by calling `train` repeatedly with the given `seed`, and after every chunk save a checkpoint to the file name obtained from `template.format(epoch=...)`, where `epoch` is the total number of epochs the object has been trained for at that moment.
