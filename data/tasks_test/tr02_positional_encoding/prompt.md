Write a PyTorch module `PositionalEncoding(max_len, d_model)` that adds sinusoidal positional information to a batch of sequences. Its `forward(x)` takes `x` of shape (N, L, d_model) with L <= max_len and returns a tensor of the same shape in which the position information of the first L positions has been combined with `x`. The encoding table has to be computed once in the constructor from the usual sine/cosine formula with angular speeds `1 / 10000^(2i / d_model)`: sine on the even feature dimensions, cosine on the odd ones. The module has no trainable parameters.
