Write a PyTorch module `Attention(hidden_dim, input_dim=None, proj_values=False)` implementing scaled dot-product attention with learned affine transformations of the query, the keys and (optionally) the values; `input_dim` defaults to `hidden_dim`. It must have the methods `init_keys(keys)` (keys of shape (N, L, input_dim), called once per batch of sources), `score_function(query)` (query of shape (N, 1, input_dim); returns the scaled scores, shape (N, 1, L)) and `forward(query, mask=None)`, which returns the context vector of shape (N, 1, hidden_dim). Where `mask` (shape (N, 1, L)) is 0 the attention paid to that source position must be (numerically) zero. The attention weights of the last call must stay available on the module, detached from the graph.
