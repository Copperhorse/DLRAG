Write a function `padding_mask(lengths, max_len)` for batches of padded sequences: `lengths` is a list or 1-D tensor with the true length of each of the N sequences. Return a boolean tensor that says, for every sequence, which of the `max_len` source positions are real (True) and which are padding (False). It is meant to be used as the `mask` of the book's attention, whose scores have shape (N, 1, L), so it must broadcast against that shape.
