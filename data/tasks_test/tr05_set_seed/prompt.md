Implement the method `set_seed(self, seed=42)` of the class `StepByStep` (write only the class with this method; `__init__` already exists). It makes training reproducible: after calling it, the random numbers drawn from PyTorch, NumPy and Python's `random` module are determined by `seed`, GPU convolution algorithms are forced to be deterministic, and the random sampler of the object's training data loader (the object has the attribute `train_loader`, which may be `None` or may use a sampler that has no random generator) is reseeded as well. It must never fail because of such a loader.
