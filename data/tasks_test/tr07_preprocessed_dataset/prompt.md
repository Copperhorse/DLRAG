Write a function `preprocessed_dataset(model, loader, device=None)` that runs a (typically frozen, pretrained) PyTorch `model` once over every mini-batch `(x, y)` of the data loader and returns a `TensorDataset` holding the model's outputs for all samples together with the corresponding labels, so that a small classifier can later be trained on those precomputed features. If `device` is None, use the device the model's parameters are on. The returned tensors live on the CPU and do not track gradients.
